# 🦁 Leonis

Discord bot multifuncional focado em segurança, moderação, administração, economia, jogos e interação.

## Módulos

- 🛡️ Segurança e anti-raid
- 🔨 Moderação
- 📜 Logs
- 👑 Administração e cargos
- 👋 Boas-vindas personalizadas
- 🔑 Reações por palavras-chave
- 💰 Economia e VIP
- 🎰 Jogos com moeda virtual
- 🎌 Interações e GIFs de anime

## Princípios de segurança

- Permissões mínimas
- Hierarquia de cargos respeitada
- Cooldowns e rate limits
- Proteção contra convites indesejados
- Anti-flood e base para anti-raid
- Segredos nunca entram no código-fonte
